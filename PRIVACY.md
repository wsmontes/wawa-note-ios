# Wawa Note Privacy Policy

Effective date: July 19, 2026

Wawa Note is developed by Wawasoft BC LTD in Victoria, British Columbia, Canada. Questions or privacy requests can be sent to [wawasoftbc@gmail.com](mailto:wawasoftbc@gmail.com).

## Summary

Wawa Note is local-first. It has no Wawa Note account, advertising, analytics, tracking, or Wawa Note cloud backend. Recordings, transcripts, notes, scans, imports, projects, AI results, and app logs are stored in the app's container on your iPhone unless you export them or explicitly enable an external processing option.

The app can work without a cloud AI provider. On-device Apple Speech, Vision OCR, capture, search, organization, and export remain available without sending content to a third-party AI service.

## Data stored on your device

Depending on the features you use, Wawa Note may store:

- audio recordings and transcription segments;
- notes, journal entries, imported documents, bookmarks, images, and scanned pages;
- transcripts, summaries, action items, embeddings, and other derived analysis;
- projects, folders, tags, annotations, and processing state;
- optional calendar, reminder, contact, and recording context selected through Apple frameworks;
- AI provider configuration and an identifier for each API key;
- diagnostic logs generated by the app.

API keys are stored in the iOS Keychain. Large artifacts are stored as files, and indexable metadata is stored with SwiftData. Face ID can be enabled to gate access to the app. Wawa Note does not upload this local library to a Wawa Note server.

## Optional processing that leaves the iPhone

### Cloud AI providers

Wawa Note includes optional integrations with OpenAI, Anthropic, Google Gemini, DeepSeek, and Groq, and can connect to a custom endpoint. Before a cloud provider can receive personal content, the app names that provider, describes the content categories, and requires an off-by-default approval.

After approval, Wawa Note may send the content needed for the feature you invoke, including recordings for remote transcription, transcripts, notes, imported text, scans or images, prompts, and derived text for analysis or embeddings. The purpose is only app functionality: transcription, description, summarization, extraction, and semantic retrieval. Wawa Note does not authorize providers to use content for advertising or cross-app tracking.

Built-in integrations use the providers' official API endpoints. Their processing, security, retention, deletion, and account-linking practices are governed by their terms and privacy policies. Because you supply an API key, a provider may associate a request with your account at that provider. Review the selected provider's policy before approving it. If its practices are not acceptable, keep approval off and use on-device processing or a model on a computer you control.

Custom cloud endpoints are destinations you choose and control. Wawa Note cannot verify or delete data retained by a custom endpoint.

### Apple cloud speech recognition

Apple Speech is configured for on-device recognition by default. If you turn on **Allow Cloud Processing**, audio may be processed by Apple when on-device recognition is unavailable or unsuitable. Apple's handling of that data is governed by Apple's privacy policy and platform terms.

### Local-network models and requested websites

When you choose LM Studio, Ollama, or another local endpoint, content is sent over your network to the computer running that model. When you save or import a web address, Wawa Note may request that address directly so it can extract the content; the website may receive ordinary request information such as your IP address. Wawa Note does not proxy these requests through its own server.

## Permissions

Wawa Note requests system permission only when a related feature needs it. These permissions can include microphone, speech recognition, camera, contacts, calendar, reminders, and Face ID. Calendar, reminder, contact, and biometric data are processed on device unless content derived from them is deliberately included in material you approve for external processing.

Recording is always initiated by an explicit user action and the app displays an active recording interface. You are responsible for obtaining any consent required to record other people.

## App privacy disclosures

Because an approved cloud provider may retain API requests beyond the time needed to return a response, Wawa Note conservatively declares these optional categories as collected for app functionality and linked to the provider account:

- Audio Data;
- Photos or Videos;
- Other User Content.

Wawa Note and its providers do not use these categories for tracking through the app. Data that remains entirely on device is not collected for App Store privacy-label purposes.

## Retention, deletion, and revoking consent

Local content remains until you delete it. Deleting an item moves it to **Inbox > Trash**; **Empty Trash** permanently removes the local database record and associated files. Deleting a cloud provider removes its configuration and API key from the Keychain. You can also edit a provider and turn off content sharing, which immediately blocks future AI requests to that provider.

Turning off approval does not delete copies that a provider may already retain. Use that provider's account controls or contact the provider to request deletion under its policy. Wawa Note has no provider-side account access and cannot perform that deletion for you.

Exports and debug logs that you share are copies under your control. Review them before sending them to another person or service.

## Security

Wawa Note relies on the iOS application sandbox, iOS Data Protection, the Keychain for API keys, and HTTPS for built-in cloud providers. Local endpoints may use HTTP on a network you control. No method of storage or transmission is completely risk-free.

## Children

Wawa Note is a general productivity app and is not directed to children under 13. The app does not knowingly operate an account system or collect children's information on a Wawa Note server.

## Changes

Material changes will be reflected in this policy and, when required, in the app's consent flow or App Store disclosures. The effective date above identifies the current version.
